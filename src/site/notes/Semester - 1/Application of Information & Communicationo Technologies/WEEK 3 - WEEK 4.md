# WEEK 3

## Fundamentals of Computer Programming

Computer programming is the process of writing instructions that tell a computer how to perform specific tasks.

### Classification of Programming Languages

```
               ┌─────────────────────────┐
               │    High-Level        │ (Python, Java, C#)
               ├─────────────────────────┤
               │    Middle-Level      │ (C, C++)
               ├─────────────────────────┤
               │    Low-Level         │ (Assembly, Machine Code)
               └─────────────────────────┘
```

> [!NOTE] TYPES
> - **Low-Level Languages**: Hardware-dependent languages that execute with minimal or no translation overhead.
>     
>     - **Machine Language**: The lowest level, consisting solely of binary code (`0`s and `1`s). It is directly executed by the CPU without translation, but is virtually unreadable by humans.
>         
>     - **Assembly Language**: Replaces binary code with human-readable mnemonics (e.g., `MOV`, `ADD`, `SUB`). It requires an **Assembler** to convert it into machine code.
>         
> - **Middle-Level Languages**: Languages like **C** and **C++** that bridge the gap between human abstraction and machine hardware. They provide high-level control structures while allowing low-level direct memory manipulation via pointers and inline assembly.
>     
> - **High-Level Languages**: Modern, highly abstracted languages designed for human readability and platform independence (e.g., **Python**, **Java**, **JavaScript**). They handle memory management automatically and require compilers or interpreters to run.
>     

### Source Code vs. Object Code

- **Source Code**: The human-readable program instructions written by a programmer in a high-level, middle-level, or assembly language (e.g., `main.py` or `program.cpp`).
    
- **Object Code**: The machine-readable binary code generated by a translator (compiler or assembler) after processing the source code. It is executed directly by the CPU.
    

### Translators: Compiler vs. Interpreter

Translators convert source code into executable object code. An **Assembler** specifically converts Assembly language to machine code, while high-level languages rely on compilers or interpreters.

| **Feature**          | **Compiler**                                                                         | **Interpreter**                                                      |
| -------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| **Execution Method** | Translates the **entire** source code into object code all at once before execution. | Translates and executes the source code **line-by-line** at runtime. |
| **Execution Speed**  | Faster execution after compilation is complete.                                      | Slower execution because translation happens on the fly.             |
| **Output File**      | Generates an independent executable file (e.g., `.exe`, `.o`).                       | Does not produce a standalone object code file.                      |
| **Error Handling**   | Displays all syntax errors at once after scanning the whole file.                    | Stops execution immediately upon encountering the first error.       |
| **Examples**         | C, C++, Rust, Go                                                                     | Python, JavaScript, Ruby                                             |

### Bug and Debugging

> [!NOTE]
> - **Bug**: An error, flaw, or fault in a software program that causes it to produce incorrect results, behave unpredictably, or crash.
>     
>     - _Syntax Errors_: Code structure violates language rules.
>         
>     - _Runtime Errors_: Errors during execution (e.g., dividing by zero).
>         
>     - _Logic Errors_: The program runs, but yields incorrect outputs due to flawed logic.
>         
> - **Debugging**: The systematic process of identifying, isolating, and fixing bugs within software using logging, test suites, or specialized tools called **debuggers**.
>     

# WEEK 4
## Computer Networking

A computer network is an interconnected group of autonomous computing devices capable of sharing resources, exchanging data, and communicating via established rules.

### Types of Networks

> [!NOTE] TYPES
> - **PAN (Personal Area Network)**: Smallest network, centered around an individual within a short range of ~10 meters (e.g., Bluetooth connection between phone and headphones).
>     
> - **LAN (Local Area Network)**: Connects devices within a limited geographical area like a home, office, or school building.
>     
> - **MAN (Metropolitan Area Network)**: Covers a larger geographic region such as a city or campus (e.g., city cable TV network or municipal Wi-Fi).
>     
> - **WAN (Wide Area Network)**: Spans broad physical boundaries, across cities, countries, or globally (e.g., the Internet).
>     

### Basic Components of a Network

> [!NOTE]
> 
> 1. **Devices / Nodes**: Endpoints connected to the network that originate, route, or receive data (e.g., PCs, laptops, smartphones, smart TVs, network printers).
>     
> 2. **Transmission Media**: The physical or wireless channels carrying data signals:
>     
>     - _Wired (Guided)_: Twisted pair cables (Ethernet), Coaxial cables, Fiber-optic cables.
>         
>     - _Wireless (Unguided)_: Radio waves (Wi-Fi), Microwaves, Infrared, Cellular (4G/5G).
>         
> 3. **Networking Hardware**: Physical devices that direct traffic and manage connections (Switches, Routers, Access Points, Network Interface Cards).
>     
> 4. **Protocols**: Standardized rules governing data transmission over a network.
>     
>     - **TCP/IP**: Core protocol suite for internet communication.
>         
>     - **HTTP/HTTPS**: Transfers web page data securely.
>         
>     - **DNS**: Translates human domain names (e.g., `google.com`) into numerical IP addresses.
>         
>     - **DHCP**: Automatically assigns IP addresses to devices on a network.
>         

### Basic Network Architecture Diagram

```
                   ┌───────────────────────┐
                   │       INTERNET        │
                   └───────────┬───────────┘
                               │
                          [ Modem ]
                               │
                         [ ROUTER ] (Directs traffic between WAN & LAN)
                               │
                       ┌───────┴───────┐
                       │               │
                  [ SWITCH ]   [ Access Point ]
                   /       \           ::: (Wireless)
            [ PC 1 ]    [ PC 2 ]   [ Smartphone ]
```

### Core Hardware Comparison: Switch vs. Router vs. Server

|**Feature**|**Switch**|**Router**|**Server**|
|---|---|---|---|
|**Primary Function**|Connects devices within the **same** local network (LAN).|Connects **different** networks together (e.g., LAN to WAN/Internet).|Computes and delivers resources, data, or services to client devices.|
|**OSI Layer**|Data Link Layer (Layer 2).|Network Layer (Layer 3).|Application Layer (Layer 7).|
|**Addressing Used**|Uses **MAC Addresses** to forward frame data.|Uses **IP Addresses** to route packet data.|Uses IP/Port combinations to serve applications.|
|**Analogy**|Intercom system inside a single building.|Post office directing mail between different cities.|A central library providing books upon request.|

### Wired vs. Wireless Networks

|**Factor**|**Wired Network (Ethernet)**|**Wireless Network (Wi-Fi)**|
|---|---|---|
|**Speed & Bandwidth**|Higher, stable speeds (up to 10+ Gbps).|Lower speeds subject to distance and interference.|
|**Reliability**|Consistent; immune to physical obstructions.|Prone to signal dropouts, wall interference, and overcrowding.|
|**Mobility**|Low; devices are tethered by cables.|High; seamless connectivity within coverage range.|
|**Security**|High; requires physical access to connect.|Moderate; vulnerable to unauthorized wireless interception if unsecured.|

### Positives and Negatives of Computer Networking

> [!NOTE] iMPACT
> 
> #### Positives
> 
> - **Resource Sharing**: Hardware (printers, storage) and software can be shared across multiple users.
>     
> - **Instant Communication**: Enables real-time messaging, video conferencing, and collaborative work globally.
>     
> - **Centralized Data Management**: Files and databases can be stored centrally for reliable backups and access control.
>     
> 
> #### Negatives
> 
> - **Security Vulnerabilities**: Connected networks expose systems to viruses, malware, and hacking threats.
>     
> - **Setup & Maintenance Costs**: Infrastructure, hardware, and ongoing administration require significant investment.
>     
> - **Single Point Failure Risks**: If central network devices (like a main router or server) fail, the entire network can go down.
>     
> 

### Cybersecurity in Networking

> [!NOTE] Explanation
> Protecting network infrastructure from unauthorized access, misuse, or theft involves key security layers:
> 
> - **Firewalls**: Software or hardware barriers that monitor and filter incoming and outgoing network traffic based on predefined security rules.
>     
> - **Encryption**: Encoding data during transmission (e.g., SSL/TLS, WPA3) so intercepted data cannot be read without a decryption key.
>     
> - **Virtual Private Networks (VPNs)**: Creates an encrypted tunnel over public networks to hide user traffic and secure remote connections.
>     
> - **Authentication & Access Control**: Multi-Factor Authentication (MFA) and permissions ensure only verified users access specific network assets.
>     

### Everyday Applications of Networking

> [!NOTE] 
> - **E-Commerce & Banking**: Online transactions, point-of-sale systems, and digital fund transfers.
>     
> - **Streaming & Entertainment**: On-demand video/audio streaming platforms (Netflix, Spotify) and multiplayer online gaming.
>     
> - **Smart Homes & IoT**: Interconnected devices (smart thermostats, security cameras, voice assistants) communicating over home networks.
>     
> - **Remote Work & Collaboration**: Cloud platforms (Google Workspace, Microsoft Teams) enabling distributed teams to work synchronously.
