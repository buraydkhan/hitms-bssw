## DBMS (Database Management System)

A Database Management System (DBMS) is software that acts as an interface between users and a database, allowing users to create, read, update, and manage data efficiently and securely.

**Types of DBMS:**

- **Relational DBMS (RDBMS):** Stores data in structured tables with rows and columns. Examples: MySQL, PostgreSQL, Oracle.
    
- **NoSQL DBMS:** Handles unstructured or semi-structured data without fixed schemas. Types include Document (MongoDB), Key-Value (Redis), Column-Family (Cassandra), and Graph (Neo4j).
    
- **Hierarchical DBMS:** Organizes data in a tree-like, parent-child structure where each child has only one parent (like a file system).
    
- **Network DBMS:** Similar to hierarchical, but allows child records to have multiple parents, creating complex relationship webs.
    
- **Object-Oriented DBMS:** Stores data as objects (similar to object-oriented programming), combining data and methods together.
    

## SQL and its 4 Core Functions

**SQL (Structured Query Language)** is the standard programming language used to manage, manipulate, and query relational databases. Its operations are categorized into four core functional sub-languages:

1. **DDL (Data Definition Language):** Defines or modifies the database structure.
    
    - _Commands:_ `CREATE` (make new tables), `ALTER` (change table structure), `DROP` (delete tables).
        
2. **DML (Data Manipulation Language):** Manages the data inside the tables (often called CRUD operations: Create, Read, Update, Delete).
    
    - _Commands:_ `INSERT` (add data), `SELECT` (retrieve data), `UPDATE` (modify data), `DELETE` (remove data).
        
3. **DCL (Data Control Language):** Controls access, permissions, and security for the database.
    
    - _Commands:_ `GRANT` (give access), `REVOKE` (remove access).
        
4. **TCL (Transaction Control Language):** Manages transactions to ensure data integrity, especially during simultaneous operations.
    
    - _Commands:_ `COMMIT` (save changes), `ROLLBACK` (undo changes), `SAVEPOINT` (set a rollback point).
    

## SDLC (Software Development Life Cycle)

The Software Development Life Cycle (SDLC) is a structured framework used by engineering teams to design, develop, test, and deploy high-quality software efficiently.

**The 7 Standard Phases:**

1. **Planning:** Defining the project scope, estimating costs, allocating resources, and identifying risks.
    
2. **Requirements Analysis:** Gathering precise technical and business requirements from stakeholders to define exactly what the software must do.
    
3. **Design:** Creating the architecture, user interfaces, data models, and system flows based on the requirements.
    
4. **Development (Coding):** Writing the actual code and building the software according to the design documents.
    
5. **Testing:** Executing the code to find and fix bugs, ensuring the software meets quality standards and requirements.
    
6. **Deployment:** Releasing the finished software to a production environment where end-users can access it.
    
7. **Maintenance:** Providing ongoing support, fixing newly discovered bugs, and releasing updates or enhancements.
