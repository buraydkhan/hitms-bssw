Class Activity No 1 

Identify the 5 ICT technologies in or around the classroom?
1. Smart Board/Projectors
2. Student Laptops/Computer 
3. Learning Management System (LMS) (e.g., Google Classroom, Canvas)
4. Document Camera / Visualizer
5. School Wi-Fi Router / Network

For each one what information does it handle? 
1. Information Handled: Visual slides, video lessons, and digital annotations.
2. Information Handled: Digital assignments, research articles, code, and typed notes.
3. Information Handled: Homework submissions, grades, course syllabi, and announcements.
4. Information Handled: Live physical images of textbook pages, handwritten solutions, or science specimens.
5. Information Handled: Web traffic, network requests, and cloud file transfers.

Who uses it?
1. Who Uses It: Teachers (and students during presentations).
2. Who Uses It: Students.
3. Who Uses It: Teachers, students, and parents.
4. Who Uses It: Teachers.
5. Who Uses It: Teachers, students, and IT staff.

How does it make work easier?
1. How It Makes Work Easier: Displays large visual media to the whole class instantly without rewriting notes on a physical board.
2. How It Makes Work Easier: Eliminates paper filing, speeds up typing, and gives immediate access to reference materials online.
3. How It Makes Work Easier: Automates grade tracking and centralizes all assignment distribution in one place.
4. How It Makes Work Easier: Shows physical objects to the entire room in real time without passing them around manually.
5. How It Makes Work Easier: Connects all classroom devices to the internet simultaneously without needing physical cables.
